# 옷사진 스튜디오

옷 사진을 넣으면 AI가 배경을 지우고, 저장해 둔 배경 위에 올려 1:1 또는 3:4 상품 사진으로 만들어 주는 PWA입니다.

## 1. 왜 이 구조로 만들었나요

받은 프롬프트 3개는 PWA, Next.js, PostgreSQL을 각각 요구해서 서로 겹치고 충돌했어요. 혼자 쓰는 툴이고 코딩 경험이 거의 없다는 점을 기준으로, 같은 기능을 가장 단순하게 하나로 합쳤습니다.

| 원래 요청 | 바꾼 방식 | 이유 |
| --- | --- | --- |
| 유료 이미지 AI API | 브라우저 안에서 도는 무료 AI | 월 비용 0원, API 키 자체가 없어 노출 위험 없음 |
| Next.js | 설치 없는 순수 HTML/JS | npm 설치, 빌드 과정 없이 파일만 올리면 끝 |
| PostgreSQL + 로그인 | 브라우저 내장 저장소(IndexedDB) | 서버가 없으니 지킬 데이터도 없고 로그인이 필요 없음 |

## 2. 폴더 구조

```
clothbg/  (폴더 없이 파일 10개)
├── index.html     앱의 뼈대 (하단 탭 메뉴 포함)
├── style.css      흰색 미니멀 디자인
├── app.js         상태 관리, 화면 전환, 4개 화면, 버튼 동작
├── ai.js          AI 배경 제거
├── compose.js     배경 + 옷 합성, 비율 맞춤, 그림자
├── db.js          내 배경 저장·삭제·목록
├── sw.js          서비스 워커: 오프라인에서도 화면 열기
├── manifest.json  홈 화면 설치 정보 (이름, 아이콘)
├── icon-192.png   앱 아이콘
└── icon-512.png   앱 아이콘
```

화면은 4개입니다. 사진(업로드), 배경(선택·출력 설정), 결과(미리보기·저장), 내 배경(관리).

## 3. 배포하기: GitHub Pages (무료, 추천)

아이패드나 컴퓨터에서 한 번만 하면 됩니다. 폴더가 없어서 파일만 한꺼번에 선택해 올리면 돼요.

1. [github.com](https://github.com)에 가입하고 로그인합니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다.
3. 이름은 `clothbg`, **Public** 선택 후 **Create repository**.
4. 화면의 **uploading an existing file** 링크를 누릅니다.
5. **choose your files**를 눌러 압축을 푼 폴더 안의 파일 10개를 모두 선택해 올리고 **Commit changes**. (README.md는 올려도, 안 올려도 괜찮아요)
6. 저장소의 **Settings** → 왼쪽 **Pages** → Branch를 `main`, 폴더 `/ (root)`로 고르고 **Save**.
7. 1~2분 뒤 `https://내아이디.github.io/clothbg/` 주소로 접속하면 끝입니다.

### Vercel을 쓰고 싶다면

1. 위 1~5번으로 GitHub에 올립니다.
2. [vercel.com](https://vercel.com)에서 GitHub 계정으로 가입합니다.
3. **Add New → Project** → `clothbg` 저장소 **Import** → 설정 그대로 **Deploy**.
4. `https://clothbg-xxxx.vercel.app` 주소가 생깁니다.

## 4. 아이폰 홈 화면에 설치하기

1. Safari로 배포한 주소에 접속합니다.
2. 아래 공유 버튼 → **홈 화면에 추가**.
3. 이제 앱처럼 아이콘을 눌러 실행합니다. 저장한 배경도 더 안정적으로 유지돼요.

## 5. 사용 순서

1. **사진**: 카메라 촬영 또는 앨범에서 여러 장 선택
2. **배경**: 기본 색상이나 내 배경 선택, 비율(1:1, 3:4)과 그림자 설정
3. **결과**: 한 장씩 자동 처리, 완료 후 저장 또는 공유
   - 아이폰은 **전체 저장** → 공유 창의 **이미지 n개 저장**으로 앨범에 한 번에 저장돼요.
   - 비율만 바꾸면 AI를 다시 돌리지 않고 즉시 다시 만들어요.

## 6. 비용

| 항목 | 월 비용 |
| --- | --- |
| 호스팅 (GitHub Pages 또는 Vercel 무료) | 0원 |
| AI 배경 제거 (브라우저 안에서 처리) | 0원 |
| 데이터 저장 (기기 안 IndexedDB) | 0원 |

**저장 용량**: 배경 사진은 자동으로 줄여서 저장해 장당 약 0.3~1MB입니다. 브라우저가 기기 여유 공간에 따라 넉넉히 허용하므로 배경 수백 장도 보통 문제없어요. 다만 이 기기, 이 브라우저 안에만 저장되니 중요한 배경 원본은 따로 보관하세요.

## 7. 꼭 알아둘 점

- **옷 색 보호**: AI는 배경만 투명하게 지우고 옷 픽셀은 그대로 둡니다. "밝게 보정"을 켜면 옷이 약 6% 밝아지므로, 원본이 어두울 때만 켜세요.
- **첫 실행**: AI 모델(수십 MB)을 내려받느라 1~2분 걸립니다. 와이파이에서 처음 실행하세요. 이후엔 빨라집니다.
- **휴대폰 성능**: 한 장에 10~30초 정도 걸릴 수 있고, 오래된 폰에서 멈추면 한 번에 넣는 사진 수를 5장 이하로 줄이세요.
- **라이선스**: AI 라이브러리(@imgly/background-removal)는 AGPL 라이선스입니다. 나 혼자 쓰는 내부 툴은 문제없지만, 이 툴을 다른 사람에게 서비스로 제공하거나 판매하려면 소스코드 공개 의무가 생기거나 상용 라이선스가 필요합니다.
- **사진 권리**: 소싱처 사진은 가공·상업적 사용이 허용되는지 먼저 확인하세요.

## 8. 내 컴퓨터에서 테스트하기 (선택)

`index.html`을 더블클릭하면 작동하지 않아요(보안상 모듈 파일을 못 읽음). 아래 중 하나로 여세요.

- VS Code 설치 → 확장 프로그램 **Live Server** 설치 → `index.html` 우클릭 → **Open with Live Server**
- Node.js가 있다면 폴더에서 `npx serve .` 실행 후 표시된 주소 접속

## 9. 문제 해결

| 증상 | 해결 |
| --- | --- |
| "AI 엔진을 불러오지 못했어요" | 인터넷 연결 확인 후 새로고침. 회사·학교 와이파이는 막혀 있을 수 있어요 |
| 처리 중 앱이 멈춤 | 사진 수를 줄이거나 다른 앱을 닫고 다시 시도 |
| 고친 코드가 반영 안 됨 | `sw.js`의 `clothbg-v1`을 `clothbg-v2`로 바꿔 다시 올리기 |
| 배경이 사라짐 | Safari는 오래 안 쓴 사이트 데이터를 지울 수 있어요. 홈 화면에 설치해 쓰세요 |

## 10. 나중에 확장하기

- **여러 기기에서 같은 배경 쓰기**: Supabase(무료 요금제, 저장소 1GB)로 `db.js`만 바꾸면 됩니다.
- **더 정교한 누끼(유료 API)**: `ai.js`의 `removeBg` 함수 안만 교체하면 됩니다. 이때 API 키는 브라우저 코드에 절대 넣지 말고, Vercel 서버리스 함수(`/api/remove-bg`)에 환경 변수로 두고 브라우저 → 내 서버 → 유료 API 순서로 호출하세요. 유료 배경 제거 API는 대략 장당 수십~수백 원 수준이라 월 300장이면 몇만 원 안팎이 예상되지만, 업체마다 요금제가 자주 바뀌니 가입 전 공식 가격표를 꼭 확인하세요.
